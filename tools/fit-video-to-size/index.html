Size limits and sources

Video size questions

What is Discord's free file limit?

Discord's free file limit is 20 MB, according to its File Attachments FAQ, read 20 Nov 2026. Nitro Basic has a 50 MB limit.

Why does email aim at 18 MB?

Gmail and Outlook.com each state a 25 MB limit. Email sends attachments base64-encoded, which adds about a third. Neither help page says whether that extra size counts, so this tool aims at 18 MB.

Is my file uploaded?

No. This page reads the file details in your browser with the File API. It does not send the video anywhere.
