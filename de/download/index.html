Wie schnell Crisp auf Ihrer macOS-Version läuft

Crisp ist für macOS 14 entwickelt und auf macOS 14 und 26 getestet. Welcher Hochskalierer läuft, hängt von Ihrem macOS ab:

  • macOS 15 Sequoia oder neuer: Core ML auf dem Grafikprozessor Ihres Macs. Volle Geschwindigkeit.
  • macOS 14: ein anderer Hochskalierer, die ncnn-Engine von Crisp, ebenfalls auf dem Grafikprozessor Ihres Macs. Das Hochskalieren dauert etwa 1,5-mal so lange.

Das Ergebnis ist in beiden Fällen gleich; nur die Wartezeit ändert sich.

Gemessen auf einem Mac Studio (M1 Ultra) im Oktober 2026: Ein 3-Sekunden-Clip, auf 720p verdoppelt, brauchte 3,4 Sekunden mit Core ML und 5,0 Sekunden mit dem ncnn-Hochskalierer, den macOS 14 nutzt. Das ist der macOS-14-Hochskalierer, gemessen auf einem neueren macOS; auf einem Mac mit macOS 14 selbst wurde er noch nicht gemessen.
